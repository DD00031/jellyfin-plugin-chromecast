Chromecast

Discovers Google Cast devices on the local network and adds them to Jellyfin's built-in cast interface on every client, including iOS/iPadOS/macOS.

Each cast uses Jellyfin sessions of the user who started it (the Chromecast signs in to Jellyfin as that user). If a user has a limit under Dashboard → Users → (user) → Max number of simultaneous user sessions, set it to 0 (unlimited), or leave room for 2 extra sessions per Chromecast on top of the devices that user is signed in on. Otherwise casting fails for that user.

Chromecasts

The devices found on your network since the server started. Give one a different name for the cast menu, hide it from the menu, or press Test to show Jellyfin's ready screen on it for a few seconds.

Settings

How often the server looks for Chromecasts on the network. A switched-on Chromecast appears within this time. If the server or your network feels slower since installing the plugin, raise it, for example to 120 or 300; new Chromecasts then take that long to show up, and nothing else changes.
How long a device may go unseen before it is removed from the cast menu.
Optional text prepended to each device's name in the cast menu, e.g. "Cast - ".
On by default: the stable receiver can't load external subtitle files (.srt next to the video) until Jellyfin releases its fix. Turn off to use the stable receiver. Matches the "Google Cast version" option available to web/Chrome users.
Opens Jellyfin on the Chromecast as soon as you connect to it in a Jellyfin app, before you play anything. Jellyfin apps don't tell the server which device you picked, so with more than one Chromecast the plugin opens the one you used last; if that was the wrong one, it closes again as soon as you do anything on the right one.
Before the first video after it opens, the Chromecast measures how fast it can download from your server, which takes several seconds (4 to 8 in testing). Turn this on if your network is fast and steady (server on a cable, Chromecast with good Wi-Fi): videos start sooner and are sent at the bitrate below. Leave it off on slow or unreliable Wi-Fi: the measurement lets Jellyfin lower the quality to what the connection can handle, which prevents stuttering and buffering.
Only used with the option above. 20 suits a 1080p Chromecast on good Wi-Fi. Lower it (8 to 12) if video stutters; raise it (40 or more) for a 4K Chromecast on a fast network. Videos above this bitrate are converted down to it.
Writes every discovery scan and every message exchanged with the Chromecast to the server log. Off by default to keep the log clean; turn on while troubleshooting. Takes effect immediately.
